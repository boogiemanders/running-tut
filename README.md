# Running Tut

Running Tut is a running clothing brand co-founded by Anders and Tetsuya ("Tut").

## The idea

Running gear that two friends actually want to train in: built for real miles, with a look you'd still wear after the run.

## The gap we see

There isn't enough designer, premium running clothing out there. Most brands pick either performance or style, and the details runners actually want get overlooked. Small example, big frustration: running pants with properly big, usable pockets. Running Tut aims to fill that gap with premium design and practical details that hold up on the run.

## Status

Early days. This repo is the home for everything we build as the brand takes shape.

## What lives here (planned)

- `brand/` for name, voice, logo, and visual identity
- `products/` for product ideas, specs, and sizing
- `suppliers/` for manufacturer research and sampling notes
- `launch/` for go-to-market plans and early marketing
- `site/` for the storefront, once there is one
